Object Oriented Programming

This repository contains coursework and lab work from the Object Oriented Programming course at **FAST NUCES**.

📖 About This Course

Object Oriented Programming (OOP) teaches how to model real-world problems using classes and objects. The course builds on programming fundamentals and introduces the four core pillars of OOP.

🗂️ Topics Covered

- Classes and objects
- Constructors and destructors
- Encapsulation and data hiding
- Inheritance (single, multilevel, multiple)
- Polymorphism (function overloading, operator overloading)
- Abstract classes and interfaces
- File handling in C++

🛠️ Language Used

C++

🚀 How to Run

1. Clone the repository
   ```bash
   git clone https://github.com/talha586/Object-Oriented-Programming.git
   ```
2. Open any `.cpp` file in your IDE
3. Compile and run:
   ```bash
   g++ filename.cpp -o output
   ./output
   ```
